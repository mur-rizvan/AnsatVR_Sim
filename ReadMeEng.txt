This is the installation package for the Ansat helicopter simulator (trainer) for Windows 10 and later operating systems.

Minimum configuration for VR:
Core i7 processor and 16 GB of RAM; RTX 2070 graphics card (or equivalent performance).
At least 5 GB of free disk space.
A less demanding configuration may suffice for non-VR mode.

 Double-click the AnsatVR_Sim_setup_V-1_0.exe file and follow the instructions to install the software package.
-----------------------------------------------------------------------------------------------------
Attention: Do not install it into a folder path that contains spaces.
-----------------------------------------------------------------------------------------------------
Currently, this software product is released strictly for testing in its minimal configuration.
To launch the simulator, simply double-click the shortcut created during the installation.
To close the simulator, just close the AnsatVR_Sim console window.
If a VR headset is detected connected to your PC upon launch, the simulator will automatically load in VR mode. If no headset is detected, the simulator will automatically load in display mode. In this mode, the simulator's screen resolution will match your monitor's resolution. A 32-inch 4K monitor is recommended, and you will only need a mouse and keyboard to interact with it. Additionally, if the program detects a connected T.FLIGHT STICK X, it can be used to control the helicopter levers in both VR and display modes.
You can find help on using the simulator in the ReadMeHelpAnsat.pdf file located in the installation folder. There you will also find a brief excerpt from the ANSAT helicopter flight manual.
In VR mode, the simulator has only been tested with the Pimax 5K XR VR headset.
